# 🧠 Web Cloner Ultime - JATHNIEL EDITION

**Version 4.1 - IA Adaptative avec Exploitation Réelle**

---

## 📋 DESCRIPTION

**Web Cloner Ultime** est un outil de clonage de sites web avec **Intelligence Artificielle adaptative**. Il explore les sites, détecte les technologies, les secrets exposés, et **exploite réellement** les vulnérabilités (SQL Injection, XSS, LFI, Command Injection, NoSQL Injection) **sans installation externe**.

---

## 🎯 FONCTIONNALITÉS (100% RÉELLES)

### 🔷 CRAWL & TÉLÉCHARGEMENT
| Fonction | Description |
|----------|-------------|
| **Crawl** | Exploration récursive des pages |
| **Téléchargement HTML** | Sauvegarde des pages |
| **Téléchargement Assets** | CSS, JS, images |
| **Fichiers sensibles** | .env, config, .git, .htaccess |
| **Multi-threading** | 5 threads simultanés |
| **Base de données** | SQLite |
| **Rapport HTML** | Génération automatique |

### 🔍 DÉTECTION
| Fonction | Détecte |
|----------|---------|
| **Technologies** | WordPress, Laravel, Django, React, Vue, etc. |
| **Secrets** | API Keys, AWS Keys, Stripe Keys, JWT, etc. |
| **Paramètres** | URL parameters, Form inputs |
| **Sécurité** | En-têtes de sécurité (CSP, HSTS, etc.) |

### 🧠 INTELLIGENCE ARTIFICIELLE
| Fonction | Description |
|----------|-------------|
| **Analyse cible** | Détecte technologies, paramètres, formulaires |
| **Score de vulnérabilité** | Calcule un score de 0 à 1 |
| **Recommandation attaques** | Choisit les meilleures attaques |
| **Apprentissage** | Apprend des succès/échecs |
| **Adaptation** | S'adapte en temps réel |
| **Persistance** | Sauvegarde les connaissances |
| **Exploration** | Teste de nouvelles techniques |
